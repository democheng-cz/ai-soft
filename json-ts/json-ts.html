JSON TYPE FORGE

JSON → TypeScript 类型生成器

INPUT

粘贴 JSON

0 条样本
多条对象会合并字段 同构对象复用类型 缺失字段生成可选属性 非法 key 自动加引号

OUTPUT

TypeScript

等待输入
基础类型判断 string / number / boolean / null / unknown / Date
数组结构合并 对象结构不一致时合并字段，差异字段自动可选
结构复用 相同对象结构只生成一个声明，避免重复
命名规范 类型名和属性名可分别选择 Pascal / camel / snake / 原样
枚举检测 多个字符串字面量自动合并为 enum 声明
日期识别 ISO 8601 日期字符串自动推断为 Date 类型
索引签名 数字后缀键自动折叠为 [key: string] 索引签名
JSON Schema 一键切换输出 JSON Schema (draft 2020-12)
